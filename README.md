## 📖 Sobre el proyecto

**GastoSmart** es una aplicación para el **control de gastos personales** pensada para gente que
abandona las apps financieras porque cargar cada gasto es tedioso.

| | |
|---|---|
| **Problema** | Las personas no saben en qué gastan su dinero. Las apps existentes piden demasiados pasos para registrar un gasto, los gastos chicos del día a día pasan desapercibidos y la mayoría de los usuarios abandona a los pocos días. |
| **Solución** | Una app **minimalista**, con carga de gastos en la menor cantidad de interacción posible, clasificación automática por categoría, panel con estadísticas claras y alertas inteligentes sobre hábitos de consumo. |
| **Propuesta de valor** | Entender en qué se va la plata **sin trabajo manual**. Registrar en segundos, ver el panorama completo y corregir hábitos a tiempo. |

Este repositorio reúne **todas las entregas del trabajo práctico**, desde la idea inicial hasta el
modelo de datos, el plan de dirección del proyecto y el prototipo navegable.
